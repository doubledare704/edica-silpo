# Product Requirements Document (PRD): Silpo Smart Shopper Agent

## 1. Vision and core objective

Silpo Smart Shopper Agent is an autonomous AI agent built on the Silpo Model Context Protocol (MCP). It transforms voice and text requests into a completed shopping cart in the app or on the website.

Instead of returning generic suggestions, the agent calculates portions, searches for SKU data through MCP, matches items to promotions, checks the budget, and builds a ready-to-order cart.

## 2. Core features and intents

| Intent | Description |
| --- | --- |
| `PARTY` | Party and event manager for menu planning, portions, drinks, and non-food items such as coal and tableware within a company budget. |
| `BUDGET` | Smart budget guard that optimizes the cart by switching items to private label alternatives and weekly promotion offers. |
| `OFFICE` | Office snack admin, planned for Phase 2, for B2B procurement and promotion monitoring. |
| `GOURMET` | Gourmet pairing and sommelier assistant, planned for Phase 2, for matching artisanal cheeses and wines. |

## 3. User interaction and multimodal input/output

- **Input:** push-to-talk voice input via the Web Audio API or text messages.
- **Output:** a reactive UI with streaming agent steps, an interactive cart card, and a spoken response generated by Respeecher TTS.

## 4. Key success metrics

- **Action-oriented output:** 100% of completed sessions return a valid `cart_url`.
- **Constraint satisfaction:** the cart is kept within the target budget within no more than three budget-adjustment iterations.

## 5. Product intent summary

The product focuses on fast, budget-aware shopping assistance for user intent-driven events and household needs, with a clear roadmap for office and gourmet use cases in later phases.
